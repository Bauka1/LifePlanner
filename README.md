# 🧠 Интеллектуальный Планировщик Задач  
### Автоматическая приоритизация + визуализация расписания (День / Неделя / Месяц / Год)

Этот проект — интерактивное приложение на **Streamlit**, которое анализирует задачи пользователя, автоматически определяет приоритеты (через GPT или fallback-алгоритм) и визуализирует расписание в удобном виде.

Приложение помогает распределять задачи на:
- **День** — тайм-блокинг + круговая диаграмма
- **Неделю** — табличное расписание
- **Месяц** — распределение задач по неделям
- **Год** — распределение приоритетов по кварталам

---

## ✨ Основные функции

### 🔹 1. Классификация задач
Система определяет тип каждой задачи:
- Деловая  
- Повседневная  
- Личная  
- Срочная  
- Образование  
- Длительная цель  
…и др.

Если GPT доступен — используется OpenAI API.  
Если GPT недоступен → встроенный fallback-алгоритм.

---

### 🔹 2. Определение приоритетов
На основе содержания задачи система определяет:
- **Высокий приоритет** (красный)
- **Средний приоритет** (желтый)
- **Низкий приоритет** (зеленый)

и сортирует задачи.

---

### 🔹 3. Поддержка четырёх периодов
| Период | Визуализация |
|--------|--------------|
| **День** | тайм-блокинг + круговая диаграмма распределения времени |
| **Неделя** | табличное расписание |
| **Месяц** | группировка по неделям |
| **Год** | разбивка задач по кварталам + приоритеты |

---

### 🔹 4. Гарантированная корректность визуализации
Пользователь задаёт минимальное количество задач для:
- дня  
- недели  
- месяца  
- года  

Это позволяет:
- избежать пустых диаграмм  
- создать визуализацию, где данные действительно информативны  

---

### 🔹 5. Полностью русский интерфейс
Все элементы UI — на русском языке.
